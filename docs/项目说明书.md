# 轻量具身智能体 · 项目说明

**一句话**：让电脑里的虚拟机械臂听懂人话——说一句"把红色方块放到盘子上"，它自己抓起来放过去。全程不买硬件，现金成本约等于零。

> 参赛：挑战杯校赛 · 科技发明制作 B 类｜11 月 18 日交 PPT（≤22 页）+ 汇总表

## 一、项目是什么

**做什么**：在物理仿真里放一条虚拟机械臂和几个方块。人打一句话，机械臂自己完成"抓起来 — 放到指定位置"。

**演示时大概看到**：输入一句话 → 屏幕打出它解析出的目标 → 机械臂自己动 → 放好了。

**怎么做，就三步：**

1. **教**：用键盘遥控机械臂，把同一个动作（从 A 抓起来，放到 B）做几十遍，画面和关节数据一起录下来。
2. **学**：用这批数据训一个小模型（ACT），让它看到画面就知道下一步怎么动，不用人再遥控。
3. **听懂**：接一个大模型当翻译，把"那个圆的、装水的"翻成具体的物体和坐标，再交给上面那个小模型执行。

**不做什么**：不造机器人、不碰硬件、不做通用智能。只做一个固定的小任务。

## 二、难点在哪

**结论先说：钱不是门槛，是折腾。** 300 块够用，卡人的是反复调试。

**1. 装环境会卡。** 版本不对就是几十行报错，可能耗掉一整天。
→ 用独立的 Python 3.12 环境，先跑通官方最小示例；卡超过一天就换更简单的例子。

**2. 遥控的手感不是你的手。** 一开始一定笨手笨脚，动作一顿一顿、抓不准。
→ 先只练一个"从 A 到 B"的极简动作，别一上来挑战精细操作。

**3. 数据脏了，训练就白费（最容易低估）。** 模型只会模仿你示范的样子：相机中途被碰过、每次起点不一样、手上带小抖动，它全学进去。典型现象是训练曲线很漂亮，机器人却对着桌子乱啄。
→ 视角固定死、每条都从同样的状态开始、宁可 30 条干净也不要 100 条脏的。

**4. 训练完 ≠ 会干活。** 它可能不动、乱动、只成功一半，而且不报错。
→ 只要求"它动了、方向大致对"；每次只改一个参数，把结果记下来。

**5. 时间最紧。** 任何一环卡两天，后面就没了。
→ 目标定成"一条任务跑通 + 录到证据"，不是"成功率高"。宁可砍任务，不砍闭环。
