## 五、千万注意

- `data/human_v1` **是唯一不可再生的数据**（手工录的），任何脚本都不许覆盖
- `scripts/teleop.py --selftest` 默认写 `data/_selftest`；指向 human_v1 会直接拒绝
- 评估一律用**没见过的种子**（40000 / 70000 / 80000 起），并且**至少 80 局**再报数
- 单组 40 局波动有 ±7 个点：昨天就因为只跑一组，把 74 条报成了 62%（真实 56%）
- 换机重跑前先跑 `scripts/diagnose_data.py`：自带自检，机器示范回放必须 100% 才往下走
- `scripts/diagnose_policy.py` 的 P1 是相对判据：满分模型的误差必须明显小于扣分模型
