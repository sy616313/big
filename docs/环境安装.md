# 环境配置说明

> 用法：**把这篇整段丢给你的 AI**，让它先探测你的机器，再按下面的约束装。你只需要在最后跑一次验收脚本，把结果贴回来。

## 一、目标

装一个能跑本项目的 Python 环境（MuJoCo 物理仿真 + LeRobot/ACT 训练 + 大模型指令解析）。

**硬件可以完全不同，版本必须一致。** 版本不一致会导致同一份数据训出来的权重不可比、甚至加载失败——那比装不上更浪费时间。

## 二、必须一致的版本（不要自作主张升级）

| 包 | 版本 | 说明 |
|---|---|---|
| Python | **3.12.x** | 3.13 / 3.14 上 MuJoCo、LeRobot 依赖经常编译失败 |
| torch | **2.11.0** | 变体（cu128/cu121/cpu）按显卡选，见第三节 |
| torchvision | **0.26.0** | 必须和 torch 配对 |
| mujoco | **3.17.0** | |
| lerobot | **0.6.1** | 训练框架，版本差异最大 |

## 三、唯一需要判断的地方：torch 装哪个变体

先探测：

```powershell
nvidia-smi --query-gpu=name,compute_cap --format=csv
```

| 探测结果 | 装哪个 | 安装源 |
|---|---|---|
| 有输出，算力 **≥ 12.0**（RTX 50 系） | `cu128` | `https://download.pytorch.org/whl/cu128` |
| 有输出，算力 **8.x / 8.6 / 8.9**（RTX 30/40 系） | `cu121` | `https://download.pytorch.org/whl/cu121` |
| 命令不存在 / 无 NVIDIA 显卡 | CPU 版 | 普通 PyPI 镜像 |
| macOS（Apple Silicon） | CPU 版即可，自动走 MPS | 普通 PyPI 镜像 |

```powershell
# 以 cu128 为例
& "<你的环境>\python.exe" -m pip install torch==2.11.0 torchvision==0.26.0 `
    --index-url https://download.pytorch.org/whl/cu128 `
    --extra-index-url https://mirrors.aliyun.com/pypi/simple
```

## 四、验收标准（唯一硬指标）

```powershell
& "<你的环境>\python.exe" scripts\check_env.py
```

必须六行全 `[OK]`：

```
[OK]   Python 3.12
[OK]   torch 2.11.0+cu128  (CUDA build 12.8)     ← 无显卡的机器这行显示 CPU
[OK]   GPU ...                                   ← 无显卡会 FAIL，属预期
[OK]   GPU 矩阵乘法跑通
[OK]   MuJoCo 3.17.0，自由落体 200 步
[OK]   LeRobot 0.6.1
```

没有 NVIDIA 显卡的机器，第 3、4 行会 FAIL —— **这是预期的**，把 `check_env.py` 里这两项当成"已知失败"就行，其余四项通过即可开工（能跑仿真、能采数据，只是训练慢）。

## 五、给 AI 的执行要求（请照做）

1. **先探测，别直接装**：操作系统、`nvidia-smi` 是否存在、compute_cap、目标盘剩余空间（要 8–10 GB）、是否已有 conda 或 Python 3.12。
2. **环境装在项目目录之外**：Windows 建议 `D:\envs\embodied`，mac/Linux 建议 `~/envs/embodied`。不要 `pip install` 到系统 Python，不要在项目目录里建 venv（会污染 git 仓库）。conda 默认装 C 盘，用 `conda create -p <路径>` 指定。
3. **按第三节选 torch 变体**，不要一律装 CPU 版，也不要给 50 系装 cu121。
4. **国内网络**：pip 走 `https://mirrors.aliyun.com/pypi/simple`；PyTorch 单个包 2.6 GB，直连官方源常卡在 0.5 MB/s，卡住就改从 `https://mirrors.aliyun.com/pytorch-wheels/<cu128|cu121>/` 下载对应 `cp312-win_amd64.whl`，再 `pip install` 本地文件。
5. **失败就停**：任何一步报错，停下来把完整报错贴出来，不要在装了一半的环境上继续装——那会让人分不清是新错还是旧错。
6. **装完必须跑第四节的验收脚本**，把六行结果原样贴回来。

## 六、四个必踩的坑

1. **Python 3.13 / 3.14 不能用。** 系统里装的是 3.14 也不影响，另建 3.12 环境即可。
2. **50 系显卡装成 cu121 会报** `no kernel image is available for execution on the device`。这不是代码问题，重装 cu128 就好。
3. **huggingface.co 国内直连不通**（实测超时）。下模型/数据集前设 `$env:HF_ENDPOINT = "https://hf-mirror.com"`。
4. **路径别带中文和空格**。项目现在在 `D:\大挑战者杯校赛` 能跑；万一某个库报奇怪的编码错，把项目复制到 `D:\embodied` 再试。

## 七、数据和权重（不需要装环境就能拿）

- 演示数据是 `data/` 下的文件夹（LeRobot 数据集格式），压缩后网盘发，解压进自己的 `data/` 就能直接用，代码不用改。
- 训练权重是 `runs/` 下的文件，同样直接传。
- **前提是版本对齐**：装完各自跑一次 `pip freeze > env_lock.txt`，发群里比对第二节那五个包的版本。
