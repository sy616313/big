# 环境配置说明

> 用法：**把这篇整段丢给你的 AI**，让它先探测你的机器，再按下面的约束装。你只需要在最后跑一次验收脚本，把结果贴回来。

## 一、目标

装一个能跑本项目的 Python 环境：MuJoCo 物理仿真 + 采集示范数据 + ACT 训练 + 大模型指令解析。

**硬件可以完全不同，关键版本必须一致。** 版本不一致会让同一份数据训出来的权重不可比，甚至加载失败——那比装不上更浪费时间。

## 二、必须一致的版本（不要自作主张升级）

| 包 | 版本 | 说明 |
|---|---|---|
| Python | **3.12.x** | 3.13 / 3.14 上 MuJoCo、LeRobot 的预编译包经常没有 |
| torch | **2.11.0** | 变体（cu128 / cu121 / cpu）按显卡选，见第三节 |
| torchvision | **0.26.0** | 必须和 torch 配对 |
| mujoco | **3.17.0** | |
| lerobot | **0.6.1** | 训练框架，版本差异最大 |
| datasets / pandas / av / pyarrow | 4.8.x / 2.3.x / 15.x / 26.x | **lerobot 对它们有硬性上界**，自己装最新版会直接 import 失败 |
| accelerate / wandb | 1.x / 0.27.x | 训练脚本要用 |

> 为什么单独列这一行：`lerobot` 装完之后**只是骨架**，`pip install lerobot` 并不会把数据集和训练依赖带上。
> 直接 `import lerobot.datasets` 会报 `'datasets' is required but not installed`。
> 而如果你随手 `pip install datasets`，会装到 5.x，超出 lerobot 的上界，照样报错。

## 三、唯一需要判断的地方：torch 装哪个变体

先探测：

```powershell
nvidia-smi --query-gpu=name,compute_cap --format=csv
```

| 探测结果 | 装哪个 | 安装源 |
|---|---|---|
| 有输出，算力 **≥ 12.0**（RTX 50 系） | `cu128` | `https://download.pytorch.org/whl/cu128` |
| 有输出，算力 **8.x / 8.6 / 8.9**（RTX 30/40 系） | `cu121` | `https://download.pytorch.org/whl/cu121` |
| 命令不存在 / 无 NVIDIA 显卡 | CPU 版 | 普通 PyPI 镜像 |
| macOS（Apple Silicon） | CPU 版即可，自动走 MPS | 普通 PyPI 镜像 |

## 四、完整安装顺序（以 cu128 为例）

```powershell
$py = "<你的环境>\python.exe"

# 1) 先装 torch（体积最大，最容易卡）
& $py -m pip install torch==2.11.0 torchvision==0.26.0 `
    --index-url https://download.pytorch.org/whl/cu128 `
    --extra-index-url https://mirrors.aliyun.com/pypi/simple

# 2) 仿真 + 训练框架（不要装 extras，会拖进用不了的 torchcodec，见第六节第 5 条）
& $py -m pip install mujoco==3.17.0 lerobot==0.6.1 `
    --extra-index-url https://mirrors.aliyun.com/pypi/simple

# 3) LeRobot 的数据集与训练依赖（版本区间照着写，别图省事）
& $py -m pip install "datasets>=4.8,<5" "pandas>=2.2,<3" "av>=15,<16" `
    "pyarrow>=21,<30" "accelerate" "wandb>=0.24,<0.28" `
    --extra-index-url https://mirrors.aliyun.com/pypi/simple
```

## 五、验收标准（唯一硬指标）

```powershell
& "<你的环境>\python.exe" scripts\check_env.py
```

七项都必须过。本机（RTX 5070 Laptop）的实际输出：

```

[OK]   3/7 MuJoCo 3.17.0，自由落体 z 1.00 → 0.21
[OK]   4/7 LeRobot 0.6.1

[OK]   6/7 LeRobotDataset / ACTPolicy / 归一化处理链 均可导入
[OK]         resnet18 预训练权重已缓存（47 MB）
[OK]   7/7 进程编码 utf-8（安全）
```

两条说明：

- **没有 NVIDIA 显卡**：第 2 项会 FAIL，属预期。能跑仿真、能采数据，训练会很慢（CPU 上大概慢 30 倍以上）。
- **`[!!]` 是警告不是失败**：符号链接那条在普通 Windows 账号上必然出现，代码里已经自动兜底，不用管。

## 六、六个必踩的坑

1. **Python 3.13 / 3.14 不能用。** 系统里装的是 3.14 也不影响，另建 3.12 环境即可。
2. **50 系显卡装成 cu121 会报** `no kernel image is available for execution on the device`。这不是代码问题，重装 cu128 就好。
3. **huggingface.co 国内直连不通**（实测超时）。下模型/数据集前设 `$env:HF_ENDPOINT = "https://hf-mirror.com"`。
4. **中文路径会炸两次，但都已经自动兜底了**：
   - MuJoCo 的 C 层打不开中文路径 → 代码改成「读文本再解析」
   - LeRobot 存视频时用系统默认编码（中文 Windows 是 GBK）写分片清单，ffmpeg 按 UTF-8 读，路径变乱码 → `collect.py` / `train_act.py` 检测到非 UTF-8 就用 `-X utf8` 重启自己。
     表现很有迷惑性：**第 1 条轨迹能存，第 2 条必挂**（因为第 1 条只移动文件、不拼接）。手动跑 lerobot 原生命令时要自己加 `-X utf8`。
5. **Windows 上别装 `torchcodec`。** 它是 `lerobot[dataset]` 的声明依赖，但和 torch 2.11 组合时 `libtorchcodec_core4.dll` 加载失败。LeRobot 会自动回落到 `pyav`，所以按第四节的写法装（不装 extras）就绕开了。
6. **resnet18 预训练权重要联网下 45 MB**（`download.pytorch.org`）。下不动的话训练会退回随机初始化，效果明显变差。可以先手动下到 `~/.cache/torch/hub/checkpoints/`。

## 七、给 AI 的执行要求（请照做）

1. **先探测，别直接装**：操作系统、`nvidia-smi` 是否存在、compute_cap、目标盘剩余空间（要 8–10 GB）、是否已有 conda 或 Python 3.12。
2. **环境装在项目目录之外**：Windows 建议 `D:\envs\embodied`，mac/Linux 建议 `~/envs/embodied`。不要 `pip install` 到系统 Python，不要在项目目录里建 venv（会污染 git 仓库）。conda 默认装 C 盘，用 `conda create -p <路径>` 指定。
3. **按第三节选 torch 变体**，不要一律装 CPU 版，也不要给 50 系装 cu121。
4. **国内网络**：pip 走 `https://mirrors.aliyun.com/pypi/simple`；PyTorch 单个包 2.6 GB，直连官方源常卡在 0.5 MB/s，卡住就改从 `https://mirrors.aliyun.com/pytorch-wheels/<cu128|cu121>/` 下载对应 `cp312-win_amd64.whl`，再 `pip install` 本地文件。
5. **失败就停**：任何一步报错，停下来把完整报错贴出来，不要在装了一半的环境上继续装——那会让人分不清是新错还是旧错。
6. **装完必须跑第五节的验收脚本**，把结果原样贴回来。

## 八、数据和权重（不需要装环境就能拿）

- 演示数据是 `data/` 下的文件夹（LeRobot 数据集格式，300 条约 72 MB），压缩后传群文件，解压进自己的 `data/` 就能直接用，代码不用改。
- 训练权重是 `runs/train/` 下的文件（单个 checkpoint 约 591 MB，含优化器状态），同样直接传。
- **前提是版本对齐**：装完各自跑一次 `pip freeze > env_lock.txt`，发群里比对第二节那几个包的版本。
