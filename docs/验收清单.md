## 二、数据流水线

```powershell
& "D:\envs\embodied\python.exe" scripts\collect.py --episodes 20 --out data\_试采
& "D:\envs\embodied\python.exe" scripts\check_dataset.py --dataset data\_试采
```

| 检查什么 | 合格标准 |
|---|---|
| 采集成功率 | 专家策略必须接近 100%。低于 95% 说明仿真参数漂了，先查再采 |
| 数据集字段 | 有 `observation.images.front` / `observation.state` / `action` 三项 |
| 关节角范围 | 在 `sim/kinematics.py` 的 `JOINT_LO/HI` 之内 |
| 夹爪开合跨度 | > 0.005，说明真的开合过（否则抓取全是空的） |
| action ≠ state | 最大差 > 0.01，否则动作列写错了 |
| 画面 | 像素标准差 > 0.02（不是纯色），首尾帧有差异 |

## 三、训练与评估

```powershell
& "D:\envs\embodied\python.exe" scripts\train_act.py --smoke        # 30 步，检查链路
& "D:\envs\embodied\python.exe" scripts\train_act.py                # 正式训练
& "D:\envs\embodied\python.exe" scripts\eval_act.py --n-episodes 20
```

| 检查什么 | 合格标准 |
|---|---|
| 训练能启动 | `--smoke` 退出码 0，`runs\train\...\checkpoints\last\pretrained_model` 里出现 `model.safetensors` |
| loss 在降 | `l1_loss` 从 0.6 以上降到 0.15 以下 |
| 训练不炸 | 显存 `mem_gb` 明显小于 8 GB；没出现 `CUDA out of memory` |
| **闭环成功率** | **50 条里至少 35 条成功（70%）**。这是唯一算数的指标 |
| 泛化 | 评估种子的方块位置必须是训练没见过的（`eval_act.py` 用 10000 起，训练用 0 起） |

**为什么不能拿 loss 当成绩**：ACT 是模仿学习，loss 低只说明它能复现示范，不说明它能看着方块调整。loss 一路降但闭环全废是常态。

### 三个对照实验（证明它真的在学，不是背轨迹）

```powershell
$ck = "runs\train\act_grasp_v2\checkpoints\last\pretrained_model"
& "D:\envs\embodied\python.exe" scripts\eval_act.py --ckpt $ck --n-episodes 30 --exec-steps 20              # 正常
& "D:\envs\embodied\python.exe" scripts\eval_act.py --ckpt $ck --n-episodes 30 --exec-steps 20 --ablate image  # 遮相机
& "D:\envs\embodied\python.exe" scripts\eval_act.py --ckpt $ck --n-episodes 30 --exec-steps 20 --ablate state  # 抹关节角
& "D:\envs\embodied\python.exe" scripts\eval_act.py --ckpt $ck --n-episodes 30 --exec-steps 20 --ood           # 分布外
```

| 实验 | 应该看到什么 | 说明 |
|---|---|---|
| 遮住相机 | 成功率接近 **0** | 掉了才说明它真的在看画面；不掉说明在背轨迹 |
| 抹掉关节角 | 明显下降但**不归零** | 画面里也能看出机械臂位置，所以还剩一部分 |
| 分布外（半径 0.25~0.285，训练只到 0.245） | 明显低于分布内 | 这就是泛化边界，也是后期要补的地方 |

> 这组实验比"成功率 97%"更能说明问题：一个背轨迹的模型，遮住相机成功率不会掉。

## 四、怎么识别我夸大（也可以套用到任何 AI 给你的交付）

1. **说"跑通了"却不给命令**：让他当场跑，跑不出来就是没通
2. **说"成功率 X%"却不给样本量**：没有 20 次以上的记录，这个数字不算数
3. **输出里没有可判定的数字**（距离、误差、退出码、耗时）：不算验证，只算演示
4. **只有截图没有产物**：看 `runs\` 里的文件时间戳是不是刚刚生成的

```powershell
Get-ChildItem "D:\大挑战者杯校赛\runs\train" -Recurse -Filter *.safetensors |
    Select-Object FullName, LastWriteTime
```

## 七、到比赛为止，真正的验收标准

| 阶段 | 验收物 | 判定 |
|---|---|---|
| 数据 | `data/` 里 ≥ 300 条 episode | 跑一次 `check_dataset.py` 全绿 |
| 训练 | `runs/train/` 里有权重 + 日志 | 任意 checkpoint 能被 `eval_act.py` 加载并跑完 20 条 |
| 闭环 | 一段 30 秒录屏 | 方块随机摆放，模型自己看着抓，20 次里 ≥ 14 次成功 |
| 集成 | 网页里输入一句话 | 大模型解析语义 → 策略执行，全程无人干预 |
| 材料 | PPT ≤ 22 页 + 视频 | 陌生人看完能复述"这是什么、证明了什么" |
