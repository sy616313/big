## 一、先搞清楚你报的是哪一类（这一步决定后面所有事）

挑战杯其实是**两个不同的比赛**，章程完全不同，别混：

| | 大挑 | 小挑 |
|---|---|---|
| 全名 | 全国大学生课外学术科技作品竞赛 | 中国大学生创业计划竞赛 |
| 作品形式 | 学术论文 / 社会调查报告 / **科技发明制作** | 商业计划书 |
| 你该报 | **科技发明制作类**（A 类=科技含量高、投入大；B 类=投入较少、带来便利） | 先进制造赛道（章程里点名了"具身智能"） |
| 评审看什么 | 学术理论水平、实际应用价值、创新意义 | 社会价值、实践过程、创新意义、发展前景、团队协作 |

✅ 出处（官方章程原文）：
- 大挑：<https://www.tiaozhanbei.net/rules>
- 小挑：<https://www.tiaozhanbei.net/rules2>

**对你这个项目最关键的一条**（大挑章程第二十四条原文）：

> 全国评审委员会推荐通过初审的……及**全部科技发明制作类作品参加展览。科技发明制作类作品必须有实物或者模型参展。**

也就是说：**报大挑的科技发明制作类，没有实物或模型是硬伤**。你计划的"硬件 + 数字孪生"正好补这一块——这不是加分项，是入场券。

⚠️ 如果报小挑，则不需要实物，但要写商业计划书（市场、竞品、商业模式、财务），这是另一套能力。

## 二、往届特等奖长什么样（我翻了官方项目库的前 5 个特等奖）

✅ 项目库：<https://xmk.tiaozhanbei.net/project/list/project/>

我实际读到的 5 个特等奖（都在首页）：

| 学校 | 项目 | 一句话结构 |
|---|---|---|
| 清华 | 后摩尔新型半导体原子级精确构筑与高性能器件应用 | 硅基芯片到极限 → 提出"籽晶自消失+脉冲气流" → 位置自准定、超失配集成 → 全链条进产业 |
| 北航 | 基于分布式无缝柔性舵面的智能变体飞行器 | 传统机翼有缝隙、效率低 → 刚柔耦合无缝舵面 → 效率/噪声/速域全面优于固定翼 |
| 北交大 | 基于电点火的新概念 ADN 基空间发动机 | 催化剂高温失活、不能冷启动 → 电点火 → 支撑新一代在轨应用 |
| 华科 | 全息波束赋形 5G 信号智能增强系统 | 5G 覆盖差/成本高/干扰大 → 全息 MIMO + 信道感知 + 干扰抑制 → 实测领先、打破垄断 |
| 南大 | 基于存算一体芯片的无线通信系统 | 能效速度到顶 → 存内计算新范式 → 能耗降两个数量级 |

**五个项目的共同套路（这比任何"写作技巧"都有用）：**

1. **先立一个"卡脖子"或"公认痛点"**，一句话说清，不铺垫
2. **提出的方法有名字**（"籽晶自消失"、"刚柔耦合无缝舵面"、"存内计算新范式"）——评委记不住模型结构，但记得住一个概念
3. **结果必须是可比的数字**：两个数量级、效率提升多少、实测领先——不是"效果良好"
4. **有实物/系统，能现场演**
5. **叙事是"全链条"**：机理 → 器件 → 系统 → 应用

对照我们自己：第 3 条我们已经有（79.4%、100%、160 局），但**第 1、2、5 条还很弱**，第 4 条正在补（硬件）。

## 三、我们的项目现在是什么、缺什么

**已有的（都是实测，能查）**：
- 从**人类遥操作示范**学会抓放：154 条示范 → 单次 79.4%（320 局，含 160 局全新场景）
- 机器示范基线 100%，证明链路没问题
- 大模型智能体层：一句话 → 拆计划 → 执行 → **看失败结果 → 换方案重试**
- 网页实时演示：随机场景、随时暂停、智能体/手动双模式
- 一整条可复现工具链（数据体检、容差测量、配对检验）

**缺的（按严重程度）**：
1. **没有实物**（大挑科技发明类的硬要求）
2. **没有一个"给谁用"的故事**——现在是"我们做了个系统"，不是"解决了谁的什么问题"
3. **指标是学术指标**（成功率/置信区间），评委更想听"省了多少人工/多少钱/多久"
4. **没有一句话的方法名**（"示范修正"、"相对动作"这些是我们的内部叫法，不构成记忆点）

## 四、改造建议（具体到动作）

### 1）数字孪生 = 补实物 + 造记忆点，一举两得

你后面要做的硬件，最好的切入点**不是"再加个真机械臂"，而是"虚实同步"**：

- 真实小机械臂 + 仿真孪生体，同一套策略代码
- 真机跑一遍，孪生体同步复现；孪生体里先试错，真机再执行
- **这正好呼应大挑章程要"实物或模型"**，而且"数字孪生"本身就是评委熟悉的概念

⚠️ 注意：如果只做"仿真里跑通"，在科技发明制作类里会很难讲；做成"虚实双跑、同一策略"，故事就成立了。

### 2）换一个叙事入口（不是"我训了个模型"）

从"技术"入口改成"场景"入口，三选一（按你们学校专业背景挑）：

- **小批量柔性上料**：产线换型频繁，重新编程成本高 → 人示范几次就能上手
- **实验室自动化**：移液/搬运重复劳动 → 一条示范教会一台廉价臂
- **教学实训**：机器人教学设备贵 → 低成本臂 + 示范学习

选一个写死，别贪多。章程里也写了"题目要准确，不要贪大"。

### 3）把指标翻译成评委听得懂的话

| 我们现在说的 | 换成评委关心的 |
|---|---|
| 154 条人类示范 → 79.4% | **采集 40 分钟人类示范**就能让一台新臂上手（对比：传统示教编程要几天） |
| 抓取点误差 14 mm → 0.4 mm | 用"对齐示范"把精度问题从数据端解决，**不换硬件、不加传感器** |
| 失败后换策略重试，最终 12/12 | **系统自己发现失败并自救**，不需要人盯着 |
| 160 局全新场景 | 所有数字都在**没见过的场景**上测的（这条在答辩时很有说服力） |

### 4）给方法起个名字

现在内部叫"示范修正 + 相对动作 + 多模态"，太长。建议打包成一个概念，例如：

- **"示范对齐"**（Demo Alignment）：把人类示范里不一致的抓取点对齐到目标中心，再训练
- **"失败驱动的自我修正"**（Failure-driven Self-Correction）：系统自己发现抓空、换策略重试

这两个是我们**真的做过、有数据**的，不是包装。名字只是让它好记。

### 5）申报书 / PPT / 答辩的结构

**申报书（大挑科技发明制作）建议章节**：
1. 作品背景与要解决的问题（1 页，讲痛点，不讲技术）
2. 国内外现状与不足（对比表：传统示教 / 强化学习 / 端到端模仿，各自的门槛）
3. 技术方案（总体框图 + 三个创新点，每个创新点配一张图和一组数据）
4. 关键技术细节（示范对齐怎么做、相对动作怎么定义、失败检测怎么触发）
5. 实测结果（表格：对照实验、消融、样本量、置信区间；**必须写"多少局、什么场景"**）
6. 与同类作品对比（有对比才有"先进"）
7. 实物/数字孪生演示方案
8. 应用前景与推广（选定的那个场景，算一笔账）
9. 团队分工与工作量（章程要求：个人作品要承担 60% 以上，集体作品要能说清谁做了什么）

**PPT（22 页上限）建议**：
| 页 | 内容 |
|---|---|
| 1 | 标题 + 一句话（问题 + 我们做了什么） |
| 2 | 痛点：一张图说清"现在要几天，我们只要 40 分钟" |
| 3–4 | 现状与不足（对比表） |
| 5 | 总体方案框图（一张图看懂全链路） |
| 6–8 | 三个创新点，每个：问题 → 做法 → 数据 |
| 9–11 | 关键实验（对照/消融/不同数据量），**每页只讲一个结论** |
| 12 | 失败案例分析（诚实反而是加分项：我们知道自己哪不行） |
| 13–14 | 网页/真机演示截图或视频 |
| 15 | 数字孪生方案 |
| 16 | 与同类对比 |
| 17 | 应用场景与成本测算 |
| 18 | 团队分工 |
| 19 | 未来计划 |
| 20 | 致谢/Q&A |

**答辩大概率会被问的 10 个问题**（提前准备，每个 30 秒能答完）：
1. 你的创新点一句话是什么？
2. 79.4% 是怎么测的？多少局？什么场景？（答不上来就废了）
3. 剩下 20% 失败是什么原因？为什么不解决？
4. 仿真里做的，真机能用吗？域差怎么处理？
5. 为什么用人类示范？机器示范不是 100% 吗？（**这题最关键**，答案是"我们的目标是让人来教，不是让工程师写程序"）
6. 大模型在里面到底做了什么？是不是套壳？（要能现场演示"失败→换方案"）
7. 和现成的视觉抓取方案（如 YOLO+抓取检测）比，优势在哪？
8. 需要多少数据、多少算力？部署成本多少？
9. 实物呢？
10. 这个东西谁会用？他们现在怎么做的？

## 五、几条硬规矩（章程原文，踩了直接取消资格）

✅ 大挑章程：
- 作品须是**近两年内**完成的学生课外成果；毕业设计/课程设计/学位论文**不能报**
- 必须由 **2 名高级职称教师推荐**；每件作品指导教师不超过 3 名
- 申报前要在学校官网**公示不少于 5 天**，截图随作品报送
- 每人限报 1 件；每校限 6 件
- "使用 AI 工具代替撰写学术论文、调查报告，将国家课题、教师科研成果包装成学生项目"= **严重违规**

✅ 小挑章程（第二十五条）：
- 不得"过度包装参赛作品，刻意追求标题吸睛效果，使用**奢华演示设计**、铺张展位布置"
- 不得"使用 AI 工具虚构项目成果"

⚠️ 对我们最实际的一条：**PPT 和展板别做花哨**。章程明确把"奢华演示设计"列为负面行为。干净、信息密度高，比炫技安全。
